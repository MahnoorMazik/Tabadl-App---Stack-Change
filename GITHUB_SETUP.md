# GitHub Setup Guide

## What was missing

Your project **was not a Git repository** — there was no `.git` folder. That’s why you couldn’t push to GitHub.

## What was done

1. **Initialized Git:** `git init` — the repo is now a valid Git project.
2. **Updated `.gitignore`:** Ignoring:
   - `/uploads` — user uploads (don’t commit)
   - `/public/uploads` — profile/media uploads
   - `prisma/db` — SQLite database
   - `tk-deployment.zip` — build artifact (contains `deploy.sh` and `deployment/` folder with app files)
3. **Staged project files:** Everything except the paths above is staged and ready to commit.

## Push to GitHub

### 1. Create a repo on GitHub

- Go to [github.com](https://github.com) → **New repository**.
- Name it (e.g. `tk.sa`).
- **Do not** add a README, .gitignore, or license (you already have them).

### 2. Commit and add remote

```bash
# Commit (first time)
git add -A
git commit -m "Initial commit"

# Add your GitHub repo as remote (replace with your repo URL)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Or with SSH:
# git remote add origin git@github.com:YOUR_USERNAME/YOUR_REPO.git

# Push
git branch -M main
git push -u origin main
```

### 3. If push asks for auth

- **HTTPS:** Use a [Personal Access Token](https://github.com/settings/tokens) instead of a password.
- **SSH:** Add your SSH key to GitHub and use the `git@github.com:...` URL.

## Ignored (not pushed)

| Path | Reason |
|------|--------|
| `uploads/` | User uploads, local data |
| `public/uploads/` | Profile/media uploads |
| `prisma/db/` | SQLite DB (create fresh or migrate on server) |
| `tk-deployment.zip` | Generated by `create-deployment-zip.sh` or `.ps1` (contains `deploy.sh` + `deployment/`) |
| `node_modules/`, `.next/` | Dependencies & build (from .gitignore) |
| `.env*` | Secrets (use `.env.example` as template) |

## Optional: line endings (`.gitattributes`)

If you hit line-ending issues (e.g. on Windows), you can add:

```
* text=auto eol=lf
*.ps1 text eol=crlf
```

Then run `git add --renormalize .` and commit.
