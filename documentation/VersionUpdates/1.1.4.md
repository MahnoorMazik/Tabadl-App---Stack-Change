# Version 1.1.4 Update

**Release Date:** January 2025

## Overview
This update includes UI improvements, terminology updates, and comprehensive Arabic language support for public pages to enhance user experience and accessibility.

---

## Changes

### 🌐 Arabic Language Support
- **Full Bilingual Support for Public Pages**
  - Added comprehensive Arabic translations for all public-facing content
  - Implemented language switcher component in header (globe icon)
  - Automatic RTL (Right-to-Left) layout support for Arabic
  - Persistent language preference stored in localStorage
  - **Pages Translated:**
    - Homepage (hero, features, services, process, testimonials, licenses, why choose, CTA)
    - About Us page
    - Contact page (all form labels and content)
    - Main Header navigation
    - Main Footer
  - **Files Created/Modified:**
    - `src/contexts/LocaleContext.tsx` (new locale context with translations)
    - `src/components/LanguageSwitcher.tsx` (new language switcher component)
    - `src/components/MainHeader.tsx` (added language switcher)
    - `src/components/MainFooter.tsx` (translated content)
    - `src/app/page.tsx` (translated homepage)
    - `src/app/about-us/page.tsx` (translated about page)
    - `src/app/contact/page.tsx` (translated contact form)
    - `src/app/layout.tsx` (added LocaleProvider)
    - `src/app/globals.css` (added RTL support styles)

### 🎯 Lead Management
- **Enabled "Add Lead" Button**
  - The "Add Lead" button in the Lead Management page was previously hidden
  - Button is now visible and functional in the filters section
  - Styled with emerald green (`bg-emerald-600 hover:bg-emerald-700`) to match the design system
  - Button text updated from "New Lead" to "Add Lead" for consistency
  - **File Modified:** `src/app/admin/leads/page.tsx`

### 📝 Terminology Updates
- **Renamed "Import Contacts" to "Import Clients"**
  - Updated sidebar menu item from "Import Contacts" to "Import Clients"
  - Updated page title in the import page
  - **Files Modified:**
    - `src/components/PermissionAwareSidebar.tsx`
    - `src/components/DynamicSidebar.tsx`
    - `src/app/admin/clients/import/page.tsx`

### 📦 Version Bump
- Updated application version from `1.1.3` to `1.1.4`
  - **File Modified:** `package.json`

---

## Technical Details

### Lead Management Button
- Removed `hidden` class from the "Add Lead" button
- Button triggers the existing `showCreateDialog` state to open the lead creation dialog
- Positioned in the filters card alongside search, status filter, and rows per page selector

### Sidebar Navigation
- Menu item maintains the same route (`/admin/clients/import`) and permissions
- Icon and functionality remain unchanged
- Only the display text has been updated for clarity

---

## Impact
- **User Experience:** Improved accessibility with visible "Add Lead" button and full Arabic language support
- **Accessibility:** Bilingual support enables Arabic-speaking users to use the platform in their native language
- **Consistency:** Better alignment of terminology across the application
- **No Breaking Changes:** All changes are UI/UX improvements with no API or database modifications
